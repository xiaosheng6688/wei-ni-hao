# 为你好 - 音频文件设置指南

## 🎵 快速获取免费音频

由于网络限制，请用以下任一方式获取音频：

### 方式1：抖音/快手搜索下载（推荐）
1. 打开抖音/快手
2. 搜索"雨声 白噪音"、"海浪声"、"咖啡馆背景音"、"森林鸟鸣"
3. 点击音频右下角"..."
4. 选择"保存本地"即可

### 方式2：喜马拉雅APP
1. 搜索"雨声"、"海浪声"、"白噪音"
2. 下载离线音频
3. 通过微信/QQ传到电脑

### 方式3：电脑端下载
访问以下免费音频网站：
- https://freesound.org（需注册）
- https://soundjay.com
- https://mynoise.net

---

## 📁 文件放置位置

将下载的MP3文件重命名后放到：
```
wei-ni-hao/assets/sounds/
├── rain.mp3     # 雨声
├── ocean.mp3    # 海浪声  
├── cafe.mp3     # 咖啡馆背景音
└── forest.mp3   # 森林鸟鸣
```

---

## ⚡ 一分钟操作指南

1. 打开抖音 → 搜索"雨声白噪音" → 下载
2. 找到文件管理器 → 内部存储/DCIM/抖音
3. 复制到电脑 → wei-ni-hao/assets/sounds/rain.mp3
4. 其他3个音频同样操作

---

## 💡 提示
- 音频文件大小建议：1-5MB
- 格式：MP3（最佳）、WAV、AAC
- 如果暂时没有音频，应用也可以正常使用，只是没有背景音
